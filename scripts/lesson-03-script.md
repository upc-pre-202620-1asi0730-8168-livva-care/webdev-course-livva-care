# Lección 3 — Contenido con listas, enlaces e imágenes

- **Duración del video:** 8 minutos y 51 segundos.
- **Objetivo:** construir contenido variado y comprensible usando elementos HTML comunes.
- **Editor:** CodePen, panel HTML.
- **Práctica:** `starter-files/lesson-03`.

## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:45 | Mostrar el objetivo: convertir una página de texto en una sección de intereses. |
| 00:45–02:15 | Crear una lista con `ul` y tres `li`. Explicar contenedor e ítems; mencionar `ol` como alternativa cuando el orden importa. |
| 02:15–04:15 | Agregar una imagen con `img`, `src` y `alt`. Explicar que `img` no encierra contenido y que `alt` describe la información útil. |
| 04:15–05:20 | Aplicar `max-width: 100%` ya incluido para evitar que la imagen se desborde. Relacionarlo con pantallas pequeñas. |
| 05:20–06:30 | Agregar un enlace descriptivo. Comparar “Haz clic aquí” con “Continuar aprendiendo en MDN”. |
| 06:30–07:40 | Revisar la indentación y la jerarquía `h1`–`h2`. Mostrar cómo leer el código por bloques. |
| 07:40–08:30 | Pausa de práctica: completar imagen, lista y enlace; añadir un cuarto interés. |
| 08:30–09:00 | Resumir la función semántica de cada elemento y anticipar la apariencia con CSS. |

## Texto en pantalla

- `ul = lista sin orden`
- `li = elemento de la lista`
- `src = dirección de la imagen`
- `alt = descripción útil`
- `El texto del enlace debe explicar su destino`

## Resultado esperado

Página con imagen adaptable, lista de cuatro intereses y enlace externo descriptivo.
