# Lección 2 — Estructura HTML, elementos y atributos

- **Duración del video:** 7 minutos y 32 segundos.
- **Objetivo:** reconocer la estructura de un documento HTML y diferenciar etiquetas, elementos y atributos.
- **Editor:** CodePen, panel HTML.
- **Práctica:** `starter-files/lesson-02`.

## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:40 | Recuperar lo aprendido con `h1` y `p`. Presentar la pregunta: ¿qué necesita un archivo HTML completo? |
| 00:40–02:20 | Mostrar `index.html` en pantalla y recorrer `doctype`, `html lang`, `head`, `meta`, `title` y `body`. Explicar cada parte con lenguaje sencillo. |
| 02:20–03:00 | Aclarar que CodePen construye automáticamente la envoltura del documento; en el panel HTML se coloca normalmente el contenido de `body`. |
| 03:00–04:05 | Diferenciar etiqueta, elemento y atributo usando `<a href="...">Visitar sitio</a>`. Resaltar `href`. |
| 04:05–05:10 | Agregar `h1`, `h2` y párrafo. Explicar jerarquía de títulos: no elegirlos por tamaño visual. |
| 05:10–06:15 | Crear un enlace a MDN con `target="_blank"` y `rel="noopener noreferrer"`. Explicar su función de forma breve. |
| 06:15–07:15 | Pausa de práctica: completar los cuatro TODO y probar el enlace. |
| 07:15–08:00 | Resumen visual de estructura, elemento y atributo. Anticipar listas e imágenes. |

## Texto en pantalla

- `Documento completo: html + head + body`
- `CodePen prepara la estructura exterior`
- `Elemento = etiquetas + contenido`
- `Atributo = información adicional`

## Resultado esperado

Una presentación con `h1`, `h2`, párrafo y enlace externo seguro.
