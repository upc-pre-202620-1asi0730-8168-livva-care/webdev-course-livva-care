
# Lección 1 — La web y tu primera etiqueta HTML

- **Duración del video:** 5 minutos y 49 segundos.
- **Objetivo:** distinguir navegador, sitio web, HTML y CSS; escribir un título y un párrafo.
- **Editor:** CodePen, paneles HTML y CSS.
- **Práctica:** `starter-files/lesson-01`.


## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:35 | Presentar el resultado final del curso: una página de perfil ficticia. Mostrarla brevemente sin explicar todavía el código. |
| 00:35–01:25 | Explicar que el navegador solicita y muestra páginas. Presentar HTML como estructura y contenido, y CSS como apariencia. Usar la comparación de una casa: estructura y decoración. |
| 01:25–02:10 | Abrir el Pen inicial. Identificar los paneles HTML, CSS y la vista previa. Aclarar que el curso no utiliza JavaScript. |
| 02:10–03:25 | Escribir `<h1>¡Hola, mundo web!</h1>`. Señalar etiqueta de apertura, contenido y etiqueta de cierre. Observar el resultado. |
