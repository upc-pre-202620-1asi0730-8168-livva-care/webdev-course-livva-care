# Lección 4 — Introducción a CSS

- **Duración del video:** 8 minutos y 20 segundos.
- **Objetivo:** reconocer selector, propiedad y valor y crear una identidad visual básica.
- **Editor:** CodePen, panel CSS.
- **Práctica:** `starter-files/lesson-04`.

## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:40 | Mostrar el antes y después de la misma página. Aclarar que el HTML no cambia de función. |
| 00:40–01:45 | Escribir una regla mínima y señalar selector, llaves, propiedad, dos puntos, valor y punto y coma. |
| 01:45–03:20 | Estilizar `body` con fondo, color de texto y `font-family`. Probar un cambio de color en vivo. |
| 03:20–04:35 | Estilizar `h1` y `h2`. Explicar que un selector de etiqueta afecta a todos los elementos de ese tipo. |
| 04:35–05:30 | Agregar `line-height` al párrafo y relacionarlo con la legibilidad. |
| 05:30–06:20 | Explicar brevemente colores hexadecimales y la importancia del contraste. No memorizar códigos. |
| 06:20–07:20 | Pausa de práctica: completar los cuatro TODO y crear una paleta propia legible. |
| 07:20–08:00 | Resumen de regla CSS y anticipación de clases y modelo de caja. |

## Texto en pantalla

- `selector { propiedad: valor; }`
- `body` afecta la página completa
- `El contraste facilita la lectura`
- `Pausa: crea una paleta legible`

## Resultado esperado

Página con fondo, tipografía, texto y títulos diferenciados sin alterar el HTML.

## Reto

Elegir una segunda combinación de colores y comprobar que el texto se lea con facilidad.
