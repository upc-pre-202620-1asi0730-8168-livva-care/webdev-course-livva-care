# Lección 7 — Errores comunes, accesibilidad y próximos pasos

- **Duración del video:** 6 minutos y 10 segundos.
- **Objetivo:** aplicar una revisión técnica y de accesibilidad a una página con errores intencionales.
- **Editor:** CodePen, paneles HTML y CSS.
- **Práctica:** `starter-files/lesson-07`.

## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:35 | Presentar el desafío: la página funciona, pero contiene problemas que deben identificarse. |
| 00:35–01:25 | Corregir la jerarquía de `h1` a `h2`. Explicar que los encabezados organizan, no solo cambian tamaños. |
| 01:25–02:05 | Escribir un `alt` útil para la imagen. Distinguir imagen informativa y decorativa. |
| 02:05–02:50 | Mejorar el texto del enlace y agregar `rel` al abrir una pestaña externa. |
| 02:50–03:40 | Corregir `.descripcon` por `.descripcion`. Mostrar cómo comparar el nombre de clase en HTML y CSS. |
| 03:40–04:35 | Reparar contraste, ancho fijo e imagen desbordada con colores legibles, `min`, `max-width` y alto automático. |
| 04:35–05:15 | Pausa: pedir que el estudiante encuentre cinco problemas antes de revisar la solución. |
| 05:15–06:10 | Lista final de revisión y cierre del curso. Invitar a construir una nueva página desde cero. |

## Texto en pantalla

- `¿La jerarquía de títulos es lógica?`
- `¿Las imágenes informativas tienen alt?`
- `¿El enlace explica su destino?`
- `¿Las clases coinciden?`
- `¿Se lee y adapta en pantallas pequeñas?`

## Resultado esperado

Versión corregida con jerarquía, texto alternativo, enlace seguro, selectores coincidentes, contraste y diseño adaptable.

## Reto final

Crear en un Pen nuevo una página temática utilizando al menos cinco elementos HTML, dos clases y una adaptación para pantalla pequeña.
