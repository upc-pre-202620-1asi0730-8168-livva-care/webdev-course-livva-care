
# Lección 6 — Proyecto: Mi rincón creativo

- **Duración del video:** 13 minutos y 39 segundos.
- **Objetivo:** integrar estructura semántica, tarjetas y diseño adaptable en una página completa.
- **Editor:** CodePen, paneles HTML y CSS.
- **Práctica:** `starter-files/lesson-06`.

## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:50 | Presentar el resultado esperado y dividirlo visualmente en encabezado, contenido y pie. |
| 00:50–02:10 | Completar `header` con `h1` y frase. Explicar que las etiquetas semánticas describen la función de cada zona. |
| 02:10–04:10 | Completar la sección de presentación con imagen, `alt`, `h2` y párrafo. Evitar información personal real. |
| 04:10–06:20 | Crear tres artículos de intereses dentro de `.cuadricula`. Usar `h3` porque están subordinados al `h2`. |
| 06:20–07:35 | Completar la sección de proyecto destacado y crear un enlace descriptivo y seguro. |
| 07:35–08:15 | Agregar el mensaje del `footer`. Revisar orden y cierre de etiquetas. |
| 08:15–09:35 | Completar `.presentacion` con Flexbox: `display`, alineación y espacio. Explicar cada propiedad visualmente. |
| 09:35–11:10 | Completar `.cuadricula` con Grid, `auto-fit` y `minmax`. Redimensionar la vista para mostrar el cambio automático. |
| 11:10–12:10 | Completar la consulta `@media` para que la presentación cambie a columna en pantallas pequeñas. |
| 12:10–13:15 | Pausa de práctica: personalizar textos y colores sin eliminar la accesibilidad ni la adaptabilidad. |
| 13:15–13:39 | Recorrer el resultado y resumir la relación HTML–CSS. Anticipar la revisión final. |

## Texto en pantalla

- `header: presentación del sitio`
- `main: contenido principal`
- `section y article: grupos con significado`
- `Flexbox: alinear una dimensión`
- `Grid: organizar filas y columnas`
- `@media: adaptar estilos a la pantalla`

## Resultado esperado

Una página completa con estructura semántica, imagen accesible, tarjetas, cuadrícula adaptable y enlace seguro.
