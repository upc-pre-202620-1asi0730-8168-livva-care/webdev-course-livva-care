
# Lección 5 — Clases, caja y contenido centrado

- **Duración del video:** 9 minutos y 2 segundos.
- **Objetivo:** reutilizar estilos con clases y controlar el espacio de una tarjeta.
- **Editor:** CodePen, paneles HTML y CSS.
- **Práctica:** `starter-files/lesson-05`.


## Guion de producción

| Tiempo | Narración y acción en pantalla |
|---|---|
| 00:00–00:45 | Mostrar dos tarjetas con el mismo estilo. Preguntar cómo evitar repetir reglas. |
| 00:45–02:00 | Agregar `class="tarjeta"` al `section`. Explicar que una clase es una etiqueta reutilizable elegida por quien programa. |
| 02:00–03:00 | Explicar la diferencia entre `.tarjeta` en CSS y `class="tarjeta"` en HTML. |
| 03:00–04:30 | Presentar el modelo de caja: contenido, `padding`, `border` y `margin`, usando una superposición visual. |
| 04:30–05:40 | Completar `.contenedor` con ancho flexible y `margin: 40px auto`. Mostrar el centrado. |
| 05:40–06:50 | Completar `.tarjeta` con fondo, relleno, borde y esquinas redondeadas. Cambiar un valor y observar. |
| 06:50–07:35 | Explicar `box-sizing: border-box` como una forma predecible de calcular tamaños. |
| 07:35–08:30 | Pausa de práctica: crear una segunda tarjeta reutilizando la clase. |
| 08:30–09:02 | Resumir clases, caja y centrado. Anticipar el proyecto integrador. |
