# Fundamentos de Desarrollo Web

## Resumen del curso

Este curso introduce a estudiantes de 12 a 17 años a la creación de páginas web con HTML y CSS. A lo largo de siete lecciones cortas, el estudiante construirá progresivamente una página de perfil ficticia llamada **Mi rincón creativo**. Todas las actividades se realizan en CodePen y solo requieren un navegador.

- **Duración total de los videos:** 59 minutos y 23 segundos.
- **Público objetivo:** estudiantes de secundaria sin experiencia en programación.
- **Prerrequisitos:** ninguno.
- **Editor:** CodePen.

## Secuencia de lecciones

### Lección 1: La web y tu primera etiqueta HTML (5:49)

- **Objetivo:** distinguir sitio web, navegador, HTML y CSS, y crear un título y un párrafo.
- **Producto:** una presentación mínima en pantalla.
- **Video:** [L01 - La web y tu primera etiqueta HTML](https://www.youtube.com/watch?v=y4COMFImE0w&list=PLEy7f8npY_x4&index=2&t=19s)
- **Práctica en CodePen:** [starter-file-01](https://codepen.io/editor/Carlosss-the-sans/pen/01a18ef0-dae6-72d7-91cb-16fd791e6275)
- **Código inicial:** [`starter-files/lesson-01`](https://github.com/upc-pre-202620-1asi0730-8168-livva-care/webdev-course-livva-care/tree/main/starter-files/lesson-01)
- **Solución:** [`completed-examples/lesson-01`](https://github.com/upc-pre-202620-1asi0730-8168-livva-care/webdev-course-livva-care/tree/main/completed-examples/lesson-01)
- **Reto:** cambiar el título y agregar un segundo párrafo.
- **Idea clave:** HTML organiza el contenido y CSS modifica su apariencia.

- **Práctica en CodePen:** [starter-file-02](https://codepen.io/editor/Carlosss-the-sans/pen/01a18f0a-eea4-7c08-83e1-e1d01fc66413)
